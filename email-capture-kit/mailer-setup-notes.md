# MailerLite Setup Notes

## Recommended platform
MailerLite

## Why
- beginner-friendly
- simple embedded forms
- welcome email automation
- enough for early growth

## What to set up first
1. Create a MailerLite account
2. Create one audience/list for Quiet Backyard Living
3. Create an embedded form for the checklist
4. Create a thank-you page or use MailerLite confirmation flow
5. Create one welcome email with the checklist link

## What we will wire into the site later
- homepage checklist form
- signup page form
- optional blog post call-to-action form

## Suggested list name
Quiet Backyard Living Subscribers
