# PART 3 — SUPER SIMPLE HOW TO USE THIS

## When creating a board
Copy the board name and board description.

## When creating a pin
Paste:
- the title
- the description
- the link
- choose the listed board
- upload the photo you want to use

## Best beginner tip
Do not overthink Pinterest. Start by creating the 5 boards, then make the first 3 pins.
