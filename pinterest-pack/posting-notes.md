# Pinterest Posting Notes

## Best first move
Create the 5 main boards first, then add the first 10 pins across them.

## Simple posting order
1. Backyard Wildlife
2. Bird-Friendly Gardens
3. Pollinator-Friendly Plants
4. Peaceful Outdoor Living
5. Berries, Herbs & Fruit Trees

## Easy starter rhythm
- Post 2–3 pins per day for the first few days
- Mix blog post pins with lifestyle and garden inspiration pins
- Link every useful pin back to the website

## Best content mix
- 3 blog post pins
- 1 checklist/freebie pin
- 3 garden/lifestyle inspiration pins
- 3 wildlife/personality pins

## Pin image guidance
- Use warm, clear real photos
- Vertical images usually perform best on Pinterest
- If you edit images later, add simple text overlays with the post title

## What matters most right now
- consistency
- useful titles
- real images
- links back to the site

## Not necessary yet
- ads
- Pinterest tag
- advanced analytics setup
