# Birdhouse Workshop — Cedar Fence Picket Project

Birdhouse build-and-decorate project made from one cedar fence picket from Home Depot.

## Project angle
A fun birdhouse assembly and decorate project for family and friends.

## Folder structure
- `finished/` — completed birdhouses
- `people/` — people with finished birdhouses
- `details/` — close-ups and construction details
- `group/` — group workshop photos
