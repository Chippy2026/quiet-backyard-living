# Quiet Backyard Living Website Starter

This folder contains a simple starter structure for Quiet Backyard Living.

## Structure
- `content/pages/` — homepage, about page, and core site pages
- `content/blog/` — blog posts
- `content/freebie/` — lead magnet content and signup-related copy
- `assets/images/` — website images
- `assets/docs/` — PDFs and downloadable files
- `config/` — basic site info and notes

This is content-first so it can be adapted to WordPress, Ghost, static site tools, or another website builder later.
